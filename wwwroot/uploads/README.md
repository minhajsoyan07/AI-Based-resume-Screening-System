# Uploads Directory

This directory stores files uploaded by users and recruiters.

## Structure

- `/resumes`: Stores resumes uploaded by applicants. Supported formats: PDF, DOCX, and Images (JPG/PNG).
- `/jobs`: Stores job circulars or related attachments uploaded by recruiters.

## Security Note

Access to these files should be managed by the application. In production, ensure this directory is not directly browsable and that proper permissions are set.
